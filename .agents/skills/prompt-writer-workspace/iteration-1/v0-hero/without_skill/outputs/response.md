For v0, you'll get the best results with a prompt that's specific about layout, mood, and content — but not so prescriptive that v0 can't make design choices.

Here's something you can paste into v0:

---

**Hero section for a SaaS landing page**

Dark, premium SaaS hero section. Deep charcoal/black background with subtle gradient accents (violet or electric blue). Clean typography — large bold headline, lighter subheadline, generous whitespace.

Layout: centered content, max-width ~1200px. Left-aligned text block with:
- Small badge/pill at top: "Coming soon" or "Now in beta"
- Headline: "Turn your ideas into content that ships"
- Subheadline: one sentence about AI-assisted publishing for developers/creators
- Primary CTA button (glow on hover) + secondary text link
- Optional: floating UI mockup or abstract gradient orb on the right

Style: modern, minimal, not generic. Subtle glassmorphism or soft border on cards. Smooth hover transitions. No stock photo clutter.

Mobile: stack vertically, headline scales down, CTA full-width.

Use shadcn/ui-style components if possible. Dark mode native.

---

**Tips for better v0 output:**
- Mention your actual product name and one-line value prop instead of the placeholder headline
- Add "avoid purple gradient clichés" if you've seen too many of those
- If you have brand colors, include them (e.g., `#6366f1` accent)
- Run it once, then iterate: "make the CTA more prominent" or "add a subtle grid background"

v0 works well when you describe the *feeling* (premium, confident, developer-focused) alongside structure.
