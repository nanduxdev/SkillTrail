# SkillTrail Design Direction

You are designing SkillTrail as a real product, not generating a generic SaaS
landing page.

## Primary objective

Create interfaces that feel:
- authored
- technically sophisticated
- editorial
- memorable
- restrained
- product-specific

The interface must not look like a generic AI startup template.

## Design process

Before coding:

1. Identify the user and their emotional state.
2. Identify the product's strongest conceptual metaphor.
3. Choose ONE visual direction.
4. Establish typography hierarchy.
5. Establish spacing rhythm.
6. Establish color/material system.
7. Decide what visual element becomes the product's signature.
8. Only then implement.

Do not begin by selecting a Tailwind component template.

## Anti-patterns

Avoid unless there is a strong product-specific reason:

- generic purple gradients
- blue/purple AI glows
- Inter as the primary display typeface
- generic glassmorphism
- floating gradient blobs
- hero + 3 cards + CTA layouts
- excessive rounded cards
- arbitrary neon borders
- meaningless dashboard charts
- decorative animations without semantic purpose
- stock illustrations
- “AI magic” sparkles as decoration
- excessive shadows
- every section looking like a card
- excessive use of gradients

## Composition

Prefer:
- asymmetric layouts
- strong editorial typography
- intentional whitespace
- unexpected scale relationships
- visual rhythm
- layered composition
- meaningful negative space
- product-specific visual motifs
- restrained but memorable motion

## Typography

Typography is part of the brand.

Use a deliberate type hierarchy.

Do not automatically choose Inter, Roboto, Arial, or system-ui
as the display face.

Choose typography based on SkillTrail's character.

## Motion

Motion must communicate:

- hierarchy
- continuity
- interaction
- state
- discovery

Do not animate simply because animation is possible.

Respect prefers-reduced-motion.

## Responsive design

Design mobile intentionally.

Do not merely stack desktop sections vertically.

Reconsider:
- hierarchy
- typography scale
- navigation
- interaction targets
- visual density
- content order

at mobile widths.

## Final quality bar

Before declaring the design complete, ask:

"What would make someone recognize this as SkillTrail
without seeing the logo?"

If the answer is "nothing", redesign the visual identity.
