## Prompt for v0

> Create a responsive hero section component for a SaaS landing page (React + Tailwind).
>
> **Layout:** Full-width hero, max-w-6xl content. Left: headline, subhead, primary CTA + secondary link. Right: product mock or abstract visual panel. Stack vertically on mobile.
>
> **Style:** Dark premium SaaS — background near #0a0a0f, subtle gradient mesh or noise, violet/cyan accent, `rounded-2xl` cards, soft border `border-white/10`, generous padding.
>
> **Typography:** Bold display headline, muted subhead, sentence-case CTAs.
>
> **Interactions:** Primary button hover glow; `focus-visible` rings on all links/buttons.
>
> **Props:** `{ title, subtitle, ctaLabel, ctaHref, secondaryLabel, secondaryHref }` with sensible defaults.
>
> **Out of scope:** Navbar, footer, pricing, auth.

---

**Target:** v0  
**Task type:** design / build  
**Assumptions:** Dark theme, B2B SaaS positioning  
**Tips:** Iterate with "tighter spacing" or "more dramatic gradient" if first pass is flat.
