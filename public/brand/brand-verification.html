Verification checklist

  • Mark geometry sampled directly from the finalized reference — same stroke widths, lengths, angle and dot placement, not redrawn from interpretation.
  • Light-mode primary remains #B44822; dark-mode primary is finalized as #D85B2A for dark surfaces and interactive accents.
  • Wordmark converted to vector outlines (Poppins Bold / Regular, matching the reference's weight contrast) — no font dependency at render time.
  • Silhouette holds up from 512px down to a 16px browser-tab favicon.
  • White version is the same geometry recolored, not redrawn — safe on any dark surface; dark-mode primary uses #D85B2A for branded interactive states.
  • No gradients, filters, masks or embedded raster data in any file.
